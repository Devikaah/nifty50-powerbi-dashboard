# Nifty 50 Performance Dashboard

## Overview
Power BI dashboard analyzing Nifty 50 performance 
from Apr 2024 to Apr 2025 using NSE India data.

## Key Insights
- All Time High: 26,277 (Sep 2024)
- All Time Low: 21,281 (Jun 2024)
- Worst Day: 4 Jun 2024 (Election Results)
- Overall Return: +19.79%
- 57% Bullish days vs 43% Bearish days

## Tools Used
- Power BI
- DAX
- NSE India Data
